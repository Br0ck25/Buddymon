# Buddymon HD Images Directory Structure

This directory mirrors the 38 asset categories of Pokémon Crystal's graphics (`assets/gfx/`), providing an organized location for high-definition replacement art and assets.

## Directory Index (38 Categories)

| Directory | Description / Intended Assets |
| :--- | :--- |
| `battle/` | Battle UI, HP bars, EXP gauges, battle status graphics |
| `battle_anims/` | Move animations, elemental effects, impact particles |
| `card_flip/` | Goldenrod Game Corner card flip minigame graphics |
| `credits/` | Ending sequence artwork and credits graphics |
| `debug/` | Debug menus and development tools |
| `diploma/` | Game completion diploma graphics |
| `emotes/` | Overworld exclamation marks, question marks, hearts |
| `evo/` | Evolution sequence backgrounds and particle effects |
| `font/` | Custom typography and dialogue font sheets |
| `footprints/` | Pokédex footprint icons |
| `frames/` | Dialogue message box decorative borders / frames |
| `icons/` | PWA icons (`icon-192.png`, `icon-512.png`), party icons |
| `intro/` | Custom intro cutscene illustrations and backgrounds |
| `mail/` | Letter stationery graphics and borders |
| `memory_game/` | Card memory minigame graphics |
| `mobile/` | Mobile adapter / stadium graphics |
| `mystery_gift/` | Mystery gift artwork and transmission screens |
| `naming_screen/` | Keyboard naming matrix and character select art |
| `new_game/` | Intro sequence transitions, clock setting UI |
| `overworld/` | Overworld objects, cut trees, boulders, signs |
| `pack/` | Bag / backpack pocket illustrations and item lists |
| `pc/` | Bill's PC box storage and deposit/withdraw UI |
| `player/` | Protagonist portraits and sprites (`boy.png`, `girl.png`, `chris.png`, `kris.png`) |
| `pokedex/` | Pokédex interface, regional maps, dex listings |
| `pokegear/` | Pokégear cards (Phone, Map, Radio, Clock) |
| `pokemon/` | Buddymon & Pokémon sprites/portraits (`bramblet/`, `bandit/`, `chomplet/`, etc.) |
| `printer/` | Game Boy Printer photo frames and stickers |
| `sgb/` | Super Game Boy borders |
| `slots/` | Slot machine reels, payouts, and minigame UI |
| `splash/` | GameFreak / custom studio intro splash logos |
| `sprites/` | Overworld walking/running character sprites |
| `stats/` | Pokémon summary screens, badge cases, stat bars |
| `tilesets/` | HD map tilesets (towns, routes, interiors, caves, water) |
| `title/` | Title screen logos, start prompts, background skies |
| `trade/` | Trading cable link sequence illustrations |
| `trainer_card/` | Trainer card layouts, badges, signatures |
| `trainers/` | Gym leaders, rival, and NPC portraits (`professor.png`, `oak.png`) |
| `unown_puzzle/` | Ruins of Alph slider puzzle graphics |

---
